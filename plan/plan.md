# Aurasyncs SEO Keyword Plan

**Goal:** we're an aging blog with a *ranking* problem (pages are indexed, not ranking). So this plan leads with **easy-to-rank, low-competition keywords** that still have real volume — pick any row near the top and it should move the needle. High-competition / high-difficulty terms are parked in **Back burner** until domain authority grows.

**Market:** United States (en). **Data:** DataForSEO Labs + Apify Google Autocomplete (fanout in `research/keyword-fanout/`). Re-run `scripts/keyword_plan.py` to refresh/expand.

### Files in this folder
- **plan.md** (this file) — the prioritized keyword queue, tiered easy → hard.
- **[new-posts.md](./new-posts.md)** — ready-to-write briefs for each 🆕 NEW keyword (suggested slug, primary + secondary keywords to target in one post).
- **[journaling.md](./journaling.md)** — the **Journaling & Prompts** track (hub-and-spoke plan around `journal prompts`, 49.5K/mo KD 5, + printable lead magnets).
- **[writing-brief.md](./writing-brief.md)** — the voice + MDX format contract the writing agent must follow (where to save, frontmatter, structure, internal linking).
- Background: full metrics + raw fanout data in `../research/keyword-fanout/`.

> **For the writing agent:** start with **writing-brief.md**, then pull your next post from **new-posts.md** (top = highest impact). Use the repo's `/b-write` command — it injects the site voice lock automatically.

### How to read
- **Vol/mo** — avg monthly US searches. **KD** — organic difficulty 0–100 (lower = easier to rank; this is the number that matters for us). **Comp** — Google Ads paid competition. **CPC** — commercial value per click.
- **Action** — 🆕 **NEW post** (no existing page targets it) · ♻️ **expand** (we have a related post — add a section / refresh it to capture this).
- **Ordering** — by impact score = √volume × ease × competition nudge. Top of each tier = highest impact for least effort.

**Snapshot:** 177 easy wins (KD ≤ 15) · 36 moderate (KD 16–30) · 11 stretch (KD 31–45) · 30 back-burner. 188 are net-new post ideas.
